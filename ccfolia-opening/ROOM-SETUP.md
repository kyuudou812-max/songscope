# ココフォリアの部屋の組み方

オープニングだけが浮かないように、部屋全体を **同じ黒・同じ廊下・同じ文字・同じ音** でつなぐ。
OPの素材は `tools/export_ccfolia.py`、部屋の素材は `tools/make_room.py` で `build/ccfolia/` に書き出す。OPの組み方は `CCFOLIA-SETUP.md`。

## 流れ

```
待機 ──▶ OP 第N話 ──▶ 探索 ⇄ 休憩 ──▶ 終了
 ▲          │
 └──────────┘ もう一度流すときは待機を経由
```

| シーン | 背景 | 前景 | マーカーパネル | BGM | ねらい |
|---|---|---|---|---|---|
| **待機** | `room/10_wait.jpg` | `room/11_grain_loop.webp` | なし | なし | 真っ黒に、ドアの隙間の縦線だけがかすかに見える。OPを見たあとで「あの線だった」と気づく。ざらつきが動くので、OPを最初から流し直す「暗転」も兼ねる（`00_reset_black.webp` の代わりに使える） |
| **OP 第N話** | `01_bg_corridor.jpg` | `epN/02_dark_epN.webp` | `epN/03_panel_epN.webp` | `epN/04_sound_epN.mp3` | `CCFOLIA-SETUP.md` のとおり |
| **探索** | `room/20_play.jpg` | なし | `room/21_card_epN.png`（左上） | `room/22_ambient_hum_loop.mp3` | OPの廊下をぼかして暗く沈めた背景。OPで打ち出した辞書カードが、そのまま画面に残る。蛍光灯のハム音がごく小さく鳴り続ける |
| **休憩** | `room/30_break.jpg` | なし | なし | なし | 待機と同じ縦線に「休憩中」 |
| **終了** | `room/40_end_epN.jpg` | なし | なし | なし | OPと同じ位置のタイトルと「第N話　終」 |

- 待機・休憩・終了の文字や線は、OPのタイトルと同じ位置（ドアの隙間の位置）に置いてある。シーンを切り替えても、目の置き場所が変わらない
- 探索の背景は、場所の説明ではなく空気だけを残すために、ぼかして暗くしてある。シナリオの場所の絵を使う場合は、同じくらい暗く沈めると OP とつながる
- 辞書カードには、どの背景に置いても読めるよう薄い黒を敷いてある。邪魔なら外してよい

## ルームデータで一度に作る
ココフォリアで書き出したルームデータ（zip）に、まだ作っていない話のシーンを足せる。
`python3 tools/build_room_data.py <書き出したルーム.zip> <出力.zip>` を実行し、出力をココフォリアで読み込む。
- いちばん新しい話の「OP／探索／終了」をお手本に、第9話までのシーンを足す（パネルの位置・大きさもお手本と同じ）
- BGMはルームデータに含まれないので、読み込んだあとにココフォリアで設定する

## 部屋の設定のおすすめ

| 項目 | おすすめ | 理由 |
|---|---|---|
| ダイスボット | クトゥルフ神話TRPG（使う版に合わせる） | |
| マス目の表示 | 消す | OPの絵や暗い背景の上に線が出ると、作り物っぽく見える |
| 盤面（前景）の大きさ | 16:9（例：32×18マス） | OPの前景・パネルを画面全体に合わせやすい |
| チャットのタブ | メイン／情報／雑談 | 雑談を分けると、メインの緊張が保たれる |
| BGMの音量 | 探索のハム音は小さめから | 会話の邪魔をしない。OPの音は大きめでよい |

## 話ごとに差し替えるもの
OP（`02`〜`04`）、探索のカード（`21_card_epN.png`）、終了の絵（`40_end_epN.jpg`）。
シーンを話ごとに作っておく（例：「OP 第三話」「探索 第三話」「終了 第三話」）か、毎回その話の素材に入れ替える。

## 確かめること
- [ ] 待機 → OP で、OPが最初から始まるか（待機のざらつきで「暗転」の役が足りるか）
- [ ] 待機の縦線と、OPで黒に切り替わったあとの縦線が、同じ位置に見えるか
- [ ] 探索のハム音が、ループの継ぎ目で途切れたり「プツッ」と鳴ったりしないか
- [ ] 辞書カードが、駒やチャットの表示と重ならない位置にあるか
