# 動画づくりで使える技術と演出のカタログ

調査日: 2026-10-08
この作業環境で**実際に動かして確かめた**ものをまとめた。サンプルは `lab/fx.html`、書き出しは `tools/render_fx.mjs`、つなぎと容量測定は `tools/assemble_fx.py`。

## 1. 使える道具（この環境で確認済み）

| 道具 | 何ができるか | 確認 |
|---|---|---|
| **HTML / CSS** | 文字組み（縦書き・約物）、ぼかし・明るさ・反転などのフィルター、3D変形 | ○ |
| **SVG フィルター** | 文字や絵をノイズで歪ませる・にじませる | ○ |
| **Canvas 2D** | 1点ずつ描く表現（粒子・ほこり・傷・走査線・懐中電灯の光） | ○ |
| **WebGL シェーダー** | 煙・霧・炎・溶けて消えるなど、計算で作る質感 | ○（ソフトウェア描画なので重い処理は遅い） |
| **Three.js** | 奥行きのある空間、カメラの移動、立体的な粒子 | ○ v0.186 |
| **GSAP** | 細かい動きの緩急（弾む・ためる・ずらして順番に出す） | ○ v3.15 |
| **ffmpeg** | 書き出し（mp4 / WebP / APNG）、色調整、ぼかし、ノイズ、つなぎ、音の加工（反響・逆再生・音程変更・揺れ） | ○ |
| **Python（numpy / Pillow）** | 音の合成（唸り・一撃・タイプ音）、画像の下ごしらえ | ○ |
| Remotion / HyperFrames / Lottie / p5.js / PixiJS / Motion Canvas | 動画づくり用の枠組み。必要なら導入できる | npm から入手可能（未導入） |

**できないこと**：動画生成AI（実写風の映像をゼロから作る）、他社AIの呼び出し（Gemini の音声など）、音を聴いての良し悪しの判断。

### 作り方の仕組み
1. HTML で画面を組み、「時刻 t のときの見た目」を決める関数を書く
2. プログラムで動かすブラウザで、1コマずつ時刻を進めてスクリーンショットを撮る
3. ffmpeg でつないで mp4（確認用）や WebP / APNG（ココフォリア用）にする

時刻から見た目が決まるので、何度書き出しても同じ映像になり、数字を1つ変えるだけで直せる。

## 2. 演出サンプル（`build/fx_reel.mp4`、各2.5秒）

容量は「その演出を画面全体・不透明のまま2.5秒、ココフォリア用 WebP にした場合」の目安。

| # | 演出 | 使った技術 | 1280×720 24fps | 640×360 12fps | ホラーOPでの使いどころ |
|---|---|---|---|---|---|
| 1 | 文字がにじみ出る | SVGフィルター | 0.30MB | 0.06MB | タイトル・一文の登場。墨や血がにじむ印象 |
| 2 | グリッチ（色ずれ・横ずれ） | CSS | 0.27MB | 0.08MB | 何かが「おかしい」瞬間。デジタル寄りの作品向き |
| 3 | 文字が粒になって崩れる | Canvas | 0.40MB | 0.07MB | 「形を失う」。タイトルの退場 |
| 4 | 縦書きが1文字ずつ降りる | GSAP | 0.06MB | 0.02MB | 一文やタイトルを、間を持たせて読ませる |
| 5 | 蛍光灯の明滅 | CSS | 0.09MB | 0.02MB | 廊下・部屋の不安感。とても軽い |
| 6 | 光の筋に舞うほこり | Canvas | 0.42MB | 0.08MB | 静かな空間に「時間が流れている」感じ |
| 7 | 渦巻く煙 | WebGLシェーダー | 0.55MB | 0.16MB | 正体の分からない気配。背景の上に薄く重ねる |
| 8 | 暗闇が周りから迫る | シェーダー | 0.15MB | 0.04MB | 視界が狭まる・追い詰められる。**このシナリオの主題に近い** |
| 9 | 古いフィルムの傷と揺れ | Canvas + CSS | 0.37MB | 0.07MB | 昔の映像・記録映像の雰囲気 |
| 10 | ビデオテープの乱れ | Canvas | **13.72MB** | 0.45MB | 記録映像系。**重すぎるので画面全体には不向き** |
| 11 | 奥へ進むカメラ | Three.js | 0.45MB | 0.09MB | ドアに少しずつ近づく。1枚の絵に奥行きを出せる |
| 12 | 焼けるように消える | シェーダー | 0.40MB | 0.09MB | 場面の切り替え |
| 13 | 一瞬だけ反転 | CSS | 0.03MB | 0.01MB | サブリミナル。**点滅は光過敏の人に配慮が必要** |
| 14 | 懐中電灯で照らす | Canvas | 0.02MB | 0.01MB | 暗闇の一部だけが見える。探索の始まり |

## 3. わかったこと

- **画素ごとにばらばらなノイズは、容量を一気に増やす。** ビデオテープ風（#10）だけが13.7MBと桁違いだった。ノイズや粒子は「小さく作って拡大する」「粒を大きく・少なくする」のが基本（霧のテストと同じ結論）。
- **暗い・動きの少ない演出は軽い。** 明滅、迫る暗闇、懐中電灯、文字の演出は0.1MB前後で、ココフォリアの容量をほとんど気にしなくていい。
- **シェーダーはソフトウェアで描くので遅いが、2.5秒なら数十秒で書き出せる。**
- **GSAP の注意点**：タイムラインは「完了を待てる値」を返すため、書き出しの仕組みにそのまま返すと永久に待ってしまう（実際に起きたので修正済み）。

## 4. このオープニングに合いそうなもの

| 区間 | 候補 | 理由 |
|---|---|---|
| ドアが浮かび上がる（2〜5秒） | #8 暗闇が迫る を逆向きに（暗闇が引いていく）、#5 明滅を弱く | 「見つめると見えてくる」という主題に合う。軽い |
| ドアをじっと見せる（3〜8秒） | #11 奥へ進むカメラ（ごくゆっくり） | 動かないドアに、見る側が近づいていく。ただし背景全体が動くので容量に注意 |
| 一文（5〜7秒） | #1 にじみ出る、#4 1文字ずつ | 今の「1文字ずつ浮かぶ」の発展形 |
| タイトル（8.6秒〜） | #1 にじみ出る | 表紙の雰囲気（和製ホラー）に合う |
| 全体の質感 | #9 フィルムの揺れ（傷は控えめ） | 粒子は細かくしすぎない |

避けたほうがよさそうなもの：#10 ビデオテープ（重い・作品の雰囲気と違う）、#13 反転（光過敏への配慮）、#2 グリッチ（和製ホラーの静かな怖さと方向が違う）。
