# ココフォリアへの組み込み手順

素材は `python3 tools/export_ccfolia.py` で `build/ccfolia/` に書き出す。
部屋全体（待機・探索・休憩・終了）の組み方は `ROOM-SETUP.md`。待機シーンは、ここで言う「暗転」シーンを兼ねる。
層の置き方は、技術検証のテストA（背景・前景・パネルが同時に動き出した）と同じ。理由は `test-results.md`。

## 使う素材

| ファイル | 置き場所 | 中身 |
|---|---|---|
| `00_reset_black.webp` | 「暗転」シーンの前景 | 真っ黒（ループ）。これを経由すると、オープニングが最初から再生される |
| `01_bg_corridor.jpg` | オープニングのシーンの背景 | 廊下の絵（全話共通） |
| `epN/02_dark_epN.webp` | 前景（画面全体に引き伸ばす） | 暗闇が引く・蛍光灯の明滅・カット後の黒。640×360 で作ってあるので引き伸ばして使う |
| `epN/03_panel_epN.webp` | マーカーパネル（画面全体の大きさ） | 塵・隙間・一文・タイトル・辞書カード |
| `epN/04_sound_epN.mp3` | BGM | オープニングの音（約16秒）のあとに無音が10分続く。BGMはループするため、OPのあとで頭から鳴り直さないようにしてある |

`02`〜`04` は話ごとに違う（明滅の回数や辞書カードが変わる）。

## シーンの作り方

### 1. 「暗転」シーン（全話共通、1つだけ）
- 背景：なし（黒）
- 前景：`00_reset_black.webp`
- BGM：なし

### 2. 「OP 第N話」シーン（話ごと）
テストAと同じ手順で、次をまとめて1つのシーンに保存する。
- 背景：`01_bg_corridor.jpg`
- 前景：`02_dark_epN.webp`（画面全体に引き伸ばす）
- マーカーパネル：`03_panel_epN.webp`（画面全体の大きさ。背景の絵とぴったり重なる位置）
- BGM：`04_sound_epN.mp3`

置いたら一度流して、タイトルの中央の列とドアの隙間が重なる位置に来ているかを確かめる（ずれていたらパネルの位置・大きさを直す）。

## 本番の流し方
1. セッションの前に「暗転」シーンにしておく（プレイヤーが入ってくる間は真っ暗）
2. 始めるときに「OP 第N話」シーンに切り替える → 約16秒で、辞書カードを打ち終えて止まる
3. 余韻のあと、セッション用のシーンに切り替える

**もう一度流すとき**は、必ず「暗転」シーンを経由してから「OP 第N話」に切り替える（何も動いていないシーンを経由すると、最後の画面のまま止まっている）。

## 音をBGMで鳴らす理由（カットインではなく）
カットインの効果音なら1回で止まるが、シーンの切り替えとカットインの表示は別々のクリックになる。人の手で2回押すと0.3〜1秒ほどずれ、黒への切り替えと「パン」が合わなくなる。
シーンの切り替えなら、映像とBGMが同時に始まることを確かめてある（`test-results.md` テストA）。そこで BGM のまま、OPのあとに無音を10分つなげてループを遠ざけた。探索のシーンに切り替えれば、BGMはハム音に替わる。

## 事前に確かめること
- [ ] 「暗転」→「OP」で、暗闇から廊下が見えてくるところから始まるか
- [ ] 隙間が黒い縦線になる瞬間と、「パン」という音が合っているか
- [ ] タイトルがドアの隙間と同じ位置に出るか
- [ ] BGMが終わったあと、ループして頭から鳴り直さないか（鳴り直す場合は、BGMのループを切るか、終わる前にシーンを切り替える）
- [ ] 「暗転」シーンに切り替えたとき、パネル（タイトルや辞書カード）が残らないか（残る場合は教えてください）
- [ ] 別のPC・スマホでも同じように見えるか
- [ ] 初めて開く人の画面でも、読み込みで遅れないか（心配なら、セッション前に一度流しておく）
