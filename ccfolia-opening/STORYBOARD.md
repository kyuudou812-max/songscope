# 絵コンテ（案A）

全9話で共通のオープニング（0〜11秒）と、話ごとの辞書カード（11〜15秒）の構成。

## 方針
- **主題は1つ**：「暗闇を見つめるほど、何かの形が見えてしまう」（パレイドリア）
- **ネタバレ禁止**：使うのは、表紙・表紙の一文・プレイヤー向け概要に出ている要素だけ。第一話以降の出来事（足音、ドアの開閉音、引っかき音など）は使わない
- **ドアは動かさない**：動かないのに何かいる気がする、という感覚をつくる
- **人物に名前を付けない**（作者の指定）
- シナリオ本文や辞書カードの文面はリポジトリに入れない（無断転載・二次配布の禁止）。文面は `episodes.local.json` に置き、git の対象外にしている

## 秒割り（v6・30fps・16〜16.3秒）

数値の正本は `opening/timing.json`（秒割り）と `opening/layout.json`（背景に合わせた位置）。映像と音の両方がここを読む。
v3 の根拠は `research/motion-graphics-and-video-skills.md`、v4 の根拠は `research/film-direction-and-detail.md`、v5 の根拠は `research/deep-study-horror-and-craft.md`。
長さは話ごとに自動で決まる：辞書カードを打ち終わってから2秒は止めて見せる（最短16秒。第六話が最長で約16.3秒）。
**30fps で作る**（技術検証で24fpsより30fpsがなめらかだった）。音と合わせる時刻は1/30秒の倍数に置く。

| 秒 | 映像 | 音 |
|---|---|---|
| 0〜1 | 真っ黒 | **蛍光灯のハム音**（100Hzとその倍音）が大きくなる。画面に映る蛍光灯が鳴らしている音 |
| 1〜2.75 | 隙間を中心に暗闇が引き、**廊下の奥の小さなドア**が見えてくる。光源は手前の天井の蛍光灯だけ | ハム音。**ごく小さな鼓動**が始まり、少しずつ速くなる |
| 3.0〜5.2 | 一文が1文字ずつ浮かぶ（ドアが見え終わってから＝注目は一度に1つ） | |
| 1〜7.6 | 蛍光灯の下に**塵がわずかに漂う**。隙間の暗さが**ごくわずかに呼吸する**（約3.4秒周期、形は出さない） | |
| 5.2〜7.6 | **ドアを見つめる時間**（約2.4秒。v3より1秒長い） | 6.6秒から逆再生の盛り上がり音 |
| 7.633 | 真っ黒に切り替わる。隙間の縦線だけが残像として残る | **一撃**（線が現れるコマと同時）。ハム音と鼓動はここで消える |
| 8.0〜9.5 | 縦線がタイトルの長さまで伸び、**同じ位置に**縦書きタイトルがにじみ出る（中央→右→左） | 一撃の余韻 |
| 9.7〜 | 左側に辞書カードが打ち出される（2コマに1文字＝1秒15文字） | 古い手動タイプライターの「タッ」を1文字に1つだけ（活字が紙越しにゴムの胴を叩く音＋鉄の本体の短い余韻）。聞き比べでB案に決定 |
| 打ち終わり〜+2秒 | 止まって余韻 | 無音 |

## 話ごとに少しずつ変わる（v5）

『P.T.』の「同じ廊下が少しずつ変わる」の考え方。毎話同じOPを流すので、プレイヤーは「いつものOP」と思って見る。そこに、**シナリオの中身に触れない小さな変化**を積み重ねる。数値の正本は `opening/escalation.json`。

| 話 | 隙間の広がり | 蛍光灯が一瞬暗くなる回数 | 隙間の呼吸の深さ | 塵の量 | 鼓動の速さ（bpm） | ハム音 |
|---|---|---|---|---|---|---|
| 第一話 | なし | 0 | 12% | 120 | 56→66 | 素直な音 |
| 第二話 | なし | 1 | 14% | 130 | 57→67 | ほぼ同じ |
| 第三話 | +1px | 1 | 16% | 140 | 58→69 | わずかに低く |
| 第四話 | +1px | 2 | 19% | 155 | 59→71 | |
| 第五話 | +2px | 2 | 22% | 170 | 60→73 | |
| 第六話 | +3px | 3 | 25% | 185 | 62→76 | ジリジリが増える |
| 第七話 | +4px | 3 | 29% | 200 | 64→79 | |
| 第八話 | +6px | 4 | 33% | 220 | 66→83 | |
| 最終話 | +8px | 5 | 38% | 240 | 68→88 | 低く、歪んだ音 |

- 蛍光灯の明滅は、切れかけた蛍光灯のように**1回ごとに長さ・暗さ・点き直しの回数・時刻がばらばら**（`tools/make_flicker.py` → `opening/flicker.json`。映像と音が同じファイルを読む）。暗いコマではハム音が落ち込み、暗くなり始めるたびに音色や強さの違う「カチッ」が鳴る。どの1秒間でも暗くなる回数は3回以下
- 最初の数話の変化はほとんど気づかれない程度にし、後半ほど分かるようにする

## ココフォリアに入れるときの書き出し設定

- **止まった背景**：JPG（画質85前後）。書き出す前に、ごく細かい粒子（σ1〜2）を混ぜて、暗いグラデーションの縞（バンディング）を防ぐ
- **動く層（アニメーションWebP）**：画質90以上。標準の75では、混ぜた粒子が圧縮で消えて縞が戻る（実験済み）
- 根拠：`research/deep-study-horror-and-craft.md` テーマ12

## ココフォリアでの層の分け方（技術検証の結果で確定）

**1つのシーンに全部入れる。** シーンを切り替えた瞬間に、背景・前景・パネル・BGMが同時に動き出すことを確かめた（`test-results.md`）。黒へのカットも素材の中で起こす。手順は `CCFOLIA-SETUP.md`。

| 置き場所 | 素材 | 中身 |
|---|---|---|
| 背景 | `01_bg_corridor.jpg` | 廊下の絵（止まっている） |
| 前景 | `02_dark_epN.webp`（640×360、引き伸ばし、1回再生） | 暗闇が引く・蛍光灯の明滅・カット後の黒 |
| マーカーパネル | `03_panel_epN.webp`（1280×720、1回再生） | 塵・隙間・一文・縦線・タイトル・辞書カード |
| BGM | `04_sound_epN.mp3` | 全部の音 |

- 塵と隙間は明滅の層より上に来るため、明滅で暗くなるコマでは素材の側で暗くしてある
- カットインは使わない（前回の続きから再生されるため）。もう一度流すときは「暗転」シーンを経由する

## 背景画像を ChatGPT で作るときの指示文（v4）

```
16:9 の横長イラスト。夜のマンションの共用廊下を、廊下の手前から奥に向かって見た構図（一点透視）。
突き当たりに玄関ドアが1枚あり、ほんの少しだけ開いている。ドアは画面の中で小さく、周りに廊下の空間を大きく残す。
ドアの隙間の奥は完全な暗闇で、何も見えない。
光源は、画面左上の手前の天井にある蛍光灯1本だけ。光は奥へ行くほど届かなくなり、ドアのまわりは暗く、隙間が画面で一番暗い。
人物・文字・ロゴ・顔に見える模様は入れない。
白黒のペン画（線画とスクリーントーン）で、全体に赤茶色の色調をうっすら重ねる。
ドアの横にインターホン、ドアの左の壁に郵便受けがある。
```

- 作った画像は 1920×1080 か 1280×720 で保存する
- 画像が決まったら、隙間と蛍光灯の位置を `opening/layout.json` に合わせる（タイトルの位置・塵・暗闇の引き方がそこから決まる）
- **採用した背景**：1枚目（ペン画・赤茶）。元の画像は `assets/bg_corridor_original.png`（1672×941）、1280×720 に縮めたものが `opening/bg.png`。位置は `opening/layout.json` に合わせ済み（隙間 x664〜689・y251〜448、ドアの板の側＝左へ広がる）
- 2枚目（アニメ塗り）は、隙間の足もとに中からの光が漏れているのと、窓の外の青空と窓明かりが目を引くため見送った
- 辞書カードは、隙間が画面の右寄りなのでタイトルと重ならない左側に置く
- 仮の背景は `tools/make_bg_placeholder.py` で作れる
