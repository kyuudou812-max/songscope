# 絵コンテ（案A）

全9話で共通のオープニング（0〜11秒）と、話ごとの辞書カード（11〜15秒）の構成。

## 方針
- **主題は1つ**：「暗闇を見つめるほど、何かの形が見えてしまう」（パレイドリア）
- **ネタバレ禁止**：使うのは、表紙・表紙の一文・プレイヤー向け概要に出ている要素だけ。第一話以降の出来事（足音、ドアの開閉音、引っかき音など）は使わない
- **ドアは動かさない**：動かないのに何かいる気がする、という感覚をつくる
- **人物に名前を付けない**（作者の指定）
- シナリオ本文や辞書カードの文面はリポジトリに入れない（無断転載・二次配布の禁止）。文面は `episodes.local.json` に置き、git の対象外にしている

## 秒割り（v3）

数値の正本は `opening/timing.json`（映像と音の両方がここを読む）。v3 の改善の根拠は `research/motion-graphics-and-video-skills.md`。

| 秒 | 映像 | 音 |
|---|---|---|
| 0〜1.5 | 真っ黒 | 耳鳴りのような低い唸りが、ゆっくり大きくなる |
| 1.5〜3.2 | 隙間を中心に、暗闇が外へ引いていき、ドアが見えてくる（ease-out） | 唸りが続く。2秒から高い耳鳴りがかすかに混ざる |
| 3.0〜5 | 一文が1文字ずつ、下から浮き上がるように現れる（ease-out） | |
| 5.6〜6.6 | ドアはそのまま動かない | **逆再生の盛り上がり音**が、カットに向かって吸い込まれる |
| 6.6 | 真っ黒に切り替わる。**隙間の縦線だけが残像として残る** | **完全な無音** |
| 6.88 | | **一撃**（映像より少し先＝Jカット） |
| 7.0〜8.5 | 縦線が縮んで、**同じ位置に**縦書きタイトルの中央の列がにじみ出る（マッチカット）。続いて右、左の列。以後もかすかに揺れる | 一撃の余韻 |

## 背景画像を ChatGPT で作るときの指示文（案）

```
16:9 の横長イラスト。マンションの共用廊下にある、少しだけ開いた玄関ドア。
ドアの隙間の奥は完全な暗闇で、何も見えない。
人物・文字・ロゴは入れない。
白黒のペン画（線画とスクリーントーン）で、全体に赤茶色の色調をうっすら重ねる。
夜で、照明は暗く、画面の端に向かって暗くなっていく。
ドアは画面の中央よりやや右に置き、隙間がはっきり分かるようにする。
ドアの横にインターホン、壁に郵便受けがある。
```

- 作った画像は、1920×1080 か 1280×720 で保存する
- 隙間に顔などの形は出さない（見る人の想像に任せる）
- 隙間の位置が変わると②の素材の位置も変わるため、画像が決まってから②を作る
