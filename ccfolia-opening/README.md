# ココフォリア用オープニング制作

CoCシナリオ「暗闇の向こうに誰も居ない事を証明して下さい」（SPLL:E187688）の開始時に、ココフォリア上で流すオープニング演出（5〜15秒）を作るプロジェクト。

## 前提条件（2026-10-08 時点）

| 項目 | 内容 |
|---|---|
| ココフォリア | **PROプラン**。1ファイル5MBまでで、アニメーションのフレーム情報は保たれる（v1.33.5の告知より。要実機確認） |
| 動画 | **mp4 / webm は使えない**。動く画像（APNG / アニメーションWebP / GIF）で表現する |
| 背景素材 | ChatGPTで生成した画像（静止画）。ペン画・赤茶の1枚を採用（`assets/bg_corridor_original.png`） |
| 立ち絵 | 使わない |
| 手直し | AviUtl ExEdit2（AviUtl2） |
| 制作 | 文字・光・粒子・切り替え効果・合成プレビューは Claude がこのリポジトリ上で生成する |

## 表現の基本方針

1本の長い動画は作れないため、**軽い素材を層ごとに重ね、シーン切替で「カット割り」をする**。

| 層 | 中身 | 形式 |
|---|---|---|
| 背景 | 一枚絵（ほぼ動かない） | JPG / 静止PNG |
| 前景・マーカーパネル | 光・霧・粒子・文字など、動く部分だけ | 透過 WebP / APNG |
| カットイン | タイトルの決め絵＋効果音 | 動く画像＋音 |
| シーン切替 | カットの切り替え | ココフォリアのシーン機能 |
| BGM | シーンに設定 | mp3 |

## ディレクトリ

- `assets/` … 採用した素材の元画像
- `test-kit/` … 技術検証用の素材（`tools/make_test_kit.py` で再生成できる）
- `tools/` … 素材を生成するスクリプト
- `opening/index.html` … オープニングの画面（文字・動き）を HTML で組んだもの。`tools/render_opening.mjs` で1コマずつ書き出す（`--layer` で層ごとに透明背景でも書き出せる）
- `STORYBOARD.md` … 絵コンテ・層の分け方・背景画像の指示文
- `CCFOLIA-SETUP.md` … ココフォリアでのシーンの組み方と流し方
- `test-results.md` … 技術検証の結果
- `fonts/`, `build/`, `episodes.local.json` … git の対象外（フォントは Google Fonts から取得。辞書カードの文面はシナリオ本文のため入れない）

## わかったこと（制作の知見）

- **画面全体を覆う半透明アニメは重い。** 1280×720・24fps・6秒の霧は、WebPで約14MB、APNGで約25MBになった。640×360・12fps・4秒に落とすと、WebP 1.5MB、APNG 2.9MBに収まった。半透明の層は小さく作って拡大して使う。
- **WebPはAPNGの約半分の容量**（同じ内容での比較）。
- **文字は HTML で組む。** Python で1文字ずつ積むより縦書き・約物・小書き文字が正確になり、直しも速い。15秒・360コマの書き出しは約3分。
- 不透明で動きの少ない絵（同期テストの背景など）は、10秒でも0.3MB程度で済む。
- **目立つ映像の変化には、同じコマで音を合わせる。** 黒へのカットで縦線が現れてから0.28秒後に一撃を鳴らす設計にしたら、「音が遅れている」と感じられた。カットの瞬間に一撃を置き、無音は一撃のあとに回した。
- **音と映像を合わせる時刻は、コマの区切り（24fpsなら1/24秒の倍数）に置く。** 6.6秒のように区切りでない時刻にすると、映像は次のコマ（6.625秒）に出て、音だけが先に鳴る。
- **合成した効果音は、周波数の偏りを数値で確かめる。** タイプ音のエネルギーの85%が6kHz以上に偏っていて、耳に痛かった。低い芯（約260Hz）＋控えめな擦れに作り直し、毎回少しずつ高さと強さを変えた。
- **打鍵の速さは実際のタイプに近づける。** 1秒25打だと音がつながって連続音に聞こえる。2コマに1文字（1秒12文字）に落とした。
- **暗いグラデーションは段差（バンディング）が出る。** 止まった背景はJPG（画質85）＋細かい粒子（σ1〜2）で、容量4KB増しで縞が消える。アニメーションWebPは画質75だと粒子が圧縮で消えて段差が戻るので、画質90以上にする（`../research/deep-study-horror-and-craft.md` テーマ12）。
- **音にも「理由」を持たせる。** 合成の低い唸り（55Hz）は、ノートPCのスピーカーではほぼ聞こえない。画面の蛍光灯が鳴らすハム音（100Hz＋倍音）に替えたら、音のおよそ半分が150〜1000Hzに入り、小さいスピーカーでも聞こえるようになった。
- **9話は「同じ廊下が少しずつ変わる」で設計する**（`opening/escalation.json`）。変化はシナリオの中身に触れない（隙間・明滅・鼓動・塵・ハム音）。
- **音程のある短い音は「可愛く」聞こえる。** タイプ音の芯に260Hzの澄んだ音を使ったら「ポコポコ」と聞こえ、怖くなかった（エネルギーの約28%が1つの高さに集中）。音程のない雑音だけで「カタッ」と作り直した（3.7%）。
- **規則正しい明滅は作り物に見える。** 同じ3コマの型を繰り返すのではなく、長さ・暗さ・点き直し・時刻を毎回ばらつかせる。ただし1秒3回以内の安全確認は自動でかける。
- **効果音は、鳴っている物の構造から組み立てる。** 「こもった低い雑音」を主役にしたタイプ音は、重い物が柔らかい面に当たる音＝地団駄に聞こえた（200Hz未満が45%）。キーボードは小さく硬い部品なので、①底に当たる短い高めの音（1〜5kHz、数ミリ秒）②離して戻る小さな2つ目の音③大きいキーは低めで金具が揺れる、が構造上自然。作り直して200Hz未満は0.4%になった。響きを数ミリ秒で消せば、共振を使っても音程（可愛さ）は出ない。
- **澄んだ音（サイン波）の重ね合わせと、7〜13ミリ秒の短いこだまは「気持ち悪い」音になる。** 人工的な響きと、金属的なうねり（コムフィルター）が出るため。帯域を絞った雑音と、雑音を鋭い共振フィルターに通す方法、短い残響の畳み込みで作る（`tools/make_audio.py` は SciPy を使う：`pip install scipy`）。
- **細かい音の密度が高すぎると「気持ち悪い」。** 1文字に小さな音を2〜3個（紙送り・戻りなど）鳴らすと1秒24〜36回になり、虫がうごめくような生理的な気持ち悪さが出た。聞き比べ（A：3つ／B：1つ／C：2文字に1つ／D：無音）でBに決定。構造上の正しさより、聞こえ方の密度を優先する。
- **音の良し悪しを言葉だけで詰めない。** 3回続けて外したあと、候補を並べた聞き比べ動画（`build/abtest/`）を作ったら1回で決まった。
- **ココフォリアでは、シーンの切り替えが唯一の「再生ボタン」。** 背景・前景・パネル・BGMは同時に動き出すが、カットインは表示していない間も再生が進むので頭から流せない。1回再生の素材は、動く素材のあるシーンを経由すると最初に戻る（`test-results.md`）。
- **APNGは少しずつ速くなる。** 1コマの長さ（1/24秒）がミリ秒に切り捨てられるためと考えられ、1分弱で0.8秒ずれた。WebPは41と42ミリ秒を組み合わせて合計を保つので、ずれない。
- **文字の層は可逆圧縮のWebPが小さくてきれい。** 透明な部分が多く、同じコマが続く素材では、可逆（3.7MB）のほうが非可逆の画質90（3.9MB）より小さく、縞も文字のにじみも出ない。
