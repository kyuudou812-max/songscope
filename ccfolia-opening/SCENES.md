# 各話の場面（背景と小物）の作り方

場面ごとの一覧と ChatGPT への指示文はシナリオの内容を含むため `scenes.local.md`（git の対象外）に置く。ここには共通の方針だけを書く。

## 方針
- **場面ごとに背景を変える**：画面の変化を増やし、いまどこにいるのかを分かりやすくする
- **画風は OP の廊下と同じ**：白黒のペン画に赤茶。ChatGPT の色のぶれは仕上げで消す
- **画像に文字を描かせない**：文字が主役の小物（貼り紙・記事・本のページ）は、こちらで文字を組んで作る（`STYLE.md` の書体）
- **人物は描かない**：NPCは立ち絵の駒で出す。群衆は顔の見えない人影だけ
- **描写のないものは描かない**：ドアの向こう・正体の書かれていない「何か」は、暗転と言葉で
- **画面の中央を空ける**：駒・カード・資料を重ねるため

## 仕上げ（`tools/make_scene_bg.py`）
```
python3 tools/make_scene_bg.py <ChatGPTの画像> <名前> [--light]
```
1. 1280×720 に切り抜く
2. 明るさだけを残し、廊下の絵の「明るさ→色」で赤茶をかけ直す（NPCの立ち絵と同じ物差し）
3. 四隅を落とし、全体を暗めにする（昼の場面は `--light` で控えめに）
4. 細かい粒子を混ぜて JPG に（縞を防ぐ）
5. 辞書カードと駒の置き場を重ねた確認用の絵も書き出す

## ココフォリアでの出し方
- 場面ごとにシーンを作り、背景だけ差し替える（差分も同じ）
- 小物は止まった画像のカットインで出す（動く画像のカットインの問題は、止まった画像には関係しない）
