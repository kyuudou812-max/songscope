# 技術検証のやり方

本番の素材を作る前に、ココフォリアで「何がどこまでできるか」を確かめるためのテストです。
所要時間は30〜40分ほどです。結果は最後の表に ○ / × / メモ で書き込んでください。

> ファイル名が `.apng.png` で終わるものは APNG です。拡張子は `.png` なので、そのままアップロードできます。

## 準備
1. ココフォリアでテスト用のルームを新しく作る
2. このフォルダのファイルをすべてダウンロードしておく

---

## テストA：同時に動き出すか（いちばん大事）

複数の層を同じタイミングで動かせるかを確かめます。
各ファイルには色付きの縦棒があり、10秒かけて左から右へ動きます。**全部の棒が縦一列にそろっていれば、同時に動き出しています。**

| ファイル | 置き場所 | 棒の色 |
|---|---|---|
| `A1_sync_bg_…webp` | 背景 | 青 |
| `A2_sync_fg_…webp` | 前景 | 赤 |
| `A3_sync_panel_…webp` | マーカーパネル（画面全体の大きさ） | 黄 |
| `A4_sync_cutin_…webp` | カットイン | 緑 |
| `A5_sync_beep_every_1s_10s.mp3` | BGM、またはカットインの効果音 | 1秒ごとに「ピッ」と鳴る。0秒と5秒は高い音 |

手順：
1. A1〜A3とBGM（A5）を1つのシーンに保存する
2. 別のシーン（真っ暗など）に切り替えてから、テスト用のシーンに切り替える
3. 確認すること：
   - 青・赤・黄の棒はそろっているか（ずれていたら、だいたい何秒ずれたか）
   - 「ピッ」という音は、棒が目盛り（0s, 1s…）を通る瞬間と合っているか
4. シーンを開いたまま、カットイン（A4。効果音にもA5を設定）を出す
   - 緑の棒は0秒から始まるか（ほかの棒とずれるのは当然。0から始まるかを見る）
   - 音と映像のずれは何秒か
5. A2を `A2b_sync_fg_…apng.png`（APNG版）に替えて同じことをする
   - WebPとAPNGで、動き出しのタイミングに差はあるか

## テストB：1回だけ再生されるか

`3, 2, 1, END` と表示して、最後で止まる素材です。

1. `B1_once_…webp` を前景に置き、シーンを切り替えて表示する
   - 3→2→1→END で止まるか（ループしないか）
2. 一度別のシーンに移ってから、もう一度このシーンに戻る
   - **最初の「3」からやり直すか、ENDのままか**（本番で何度も使えるかが決まる）
3. `B2_once_…apng.png`（APNG版）でも同じことをする

## テストC：大きいファイルでも劣化しないか（PRO）

アップロードして表示し、画質が荒れていないか、カクつかないかを見ます。
左上の時間表示がなめらかに進むかも確認してください。

| ファイル | 中身 |
|---|---|
| `C_size_1280x720_q30_1.74MB_5s.webp` | 1280×720、画質低め（約1.7MB） |
| `C_size_1280x720_q75_2.41MB_5s.webp` | 1280×720、画質ふつう（約2.4MB） |
| `C_size_1920x1080_q80_3.69MB_5s.webp` | 1920×1080（約3.7MB） |

- アップロードできるか
- 色の縞（帯状のムラ）が出ていないか
- 読み込みにかかる時間（何秒くらいで動き出すか）

## テストD：半透明（霧）の見え方

`D1_fog_…webp` と `D2_fog_…apng.png` を、背景の上で見比べます。

> 霧の素材は **640×360 の小さいサイズ**で作ってあります。画面全体の大きさで作ると、それだけで14〜25MBになり、上限の5MBを超えてしまったためです。
> 前景またはマーカーパネルに置き、**画面全体に引き伸ばして**表示してください。

- 引き伸ばしても、ぼやけ方が自然に見えるか（霧ならぼやけていても問題ないはず）
- 霧のふちがギザギザになっていないか
- 動きはなめらかか
- 見た目に差があるか

## テストE：なめらかさ（フレームレート）

`E_fps12` / `E_fps24` / `E_fps30` を順番に表示して、白い玉の動きを見比べます。

- 12fpsはカクカクして見えるか
- 24fpsと30fpsに違いはあるか
