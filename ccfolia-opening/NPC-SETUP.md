# NPCの立ち絵の作り方

人物ごとの一覧と ChatGPT への指示文は、シナリオの内容を含むため `npcs.local.md`（git の対象外）に置く。ここには、どの人物にも共通する方針だけを書く。

## 方針
- **名前を付けない**（作者の指定）。駒の名前は本文での呼ばれ方（役割）にする
- **本文で姿が出る人だけを駒にする**。声だけの存在や、姿を見せてはいけない存在は駒にしない
- **画風は背景と同じ**：白黒のペン画に赤茶色を薄く重ねる。PLの立ち絵（カラー）と並べたとき、NPCだけが輪郭の定まらない存在に見えるのは、シナリオの主題（形を与える）に合っている
- **光は左上の蛍光灯から**。置き場の光（`room/51_slot_npcN.webp`）と向きをそろえる
- **体は少し左を向く**。NPCの置き場は前景の右にあり、PCは左下に並ぶため

## 仕上げ（`tools/make_npc_portrait.py`）
```
python3 tools/make_npc_portrait.py <ChatGPTの画像> <出力名>
```
1. 背景を抜く（透明でなければ、外周から続く地の色だけを抜く。人物の中の白は残す）
2. 明るさだけを残し、廊下の絵（`opening/bg.png`）の「明るさ→色」の対応で色をかけ直す。ChatGPT は1枚ごとに色味がぶれるので、全員を同じ物差しにそろえる。真っ白・真っ黒にはしない（`STYLE.md` の `#eeece8` と `#040404` の間）
3. 人物の範囲で切り抜き、高さ 1200px の WebP にする（PNG はココフォリアで256色に変換される）
4. 確認用に、探索の背景と NPC1 の置き場に駒サイズ40で立たせた絵を書き出す

## ココフォリアでの設定
- 駒サイズ 40、「盤面キャラクター一覧に表示しない」
- 出番まで盤面から下げておき、登場の場面で NPC1 の置き場に出す
