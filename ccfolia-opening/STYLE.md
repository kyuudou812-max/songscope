# 表示物の決まり（フォント・色）

OP・部屋・説明用の図まで、画面に出すものはすべてこの表から選ぶ。新しい色や書体を足さない。
もとは OP（`opening/index.html`）と部屋の止め絵（`opening/room.html`）で使っている値。

## 書体
| 用途 | 書体 | 例 |
|---|---|---|
| タイトル・タイトル上の小さな見出し | Zen Kaku Gothic New（`fonts/ZenKakuGothicNew-Medium.ttf`） | 「暗闇の向こうに…」「クトゥルフ神話TRPG」 |
| それ以外の文字すべて（一文・辞書カード・案内・ラベル） | しっぽり明朝（`fonts/ShipporiMincho-Medium.ttf`） | 「まもなく始まります」「第三話」「PC 1」 |

- ゴシックはタイトルだけに使う。ラベルや案内をゴシックにすると、OPの文字と別物に見える
- 文字の間はやや広く（0.1〜0.3em）。英数字も明朝で組む

## 色
| 名前 | 値 | 用途 |
|---|---|---|
| 黒 | `#040404` | 画面の黒、文字の影 |
| タイトルの白 | `#eeece8` | タイトル |
| 文字の白 | `#e1dcd6` | 辞書カード、一文（`#ded8d2`） |
| 縦線 | `#d9d3cd` | ドアの隙間の線 |
| 控えめな文字 | `#b9b1aa` | 「第N話　終」、駒の置き場のラベル |
| いちばん控えめな文字 | `#8d857e` | 「まもなく始まります」「休憩中」 |
| 蛍光灯の光 | `#ecd6b8`（236, 214, 184） | 光の円すい・光だまり |
| 背景の赤茶 | 廊下の絵の色味 | 新しい絵は、廊下の絵と同じ赤茶を薄く重ねる |

- 青・緑・純白など、表にない色は使わない。冷たさを出したいときは、同じ色を暗く・薄くする
- 文字の下に四角い地を敷かない（暗い背景から浮く）。読みにくいときは、文字の形に沿ったぼんやりした影を敷く

## 説明用の図
配置案などの説明用の図も、ラベルはこの表の書体と色で描く（色分けが要るときは、控えめな文字の白と蛍光灯の光の2色まで）。
